# Artifacts

Store sanitized, durable outputs of engineering discussions: checklists, plans, diagrams, and finalized summaries. Exclude raw private discussion logs and confidential project material.

## Accepted workflow artifact templates

- **[Workflow artifact index (English)](./workflows/README.md)** — seven Accepted v1.0 workflows, reusable copy/paste artifacts, Jira/MR-first usage and Codex handoff guidance.
- **[ดัชนี Artifact ภาษาไทย](./workflows/README.th.md)** — แม่แบบภาษาไทยทั้ง 7 Workflow พร้อมคำแนะนำให้ Codex ใช้งานต่อ
- All stages are available in paired files: `artifacts/workflows/<stage>.md` and `artifacts/workflows/<stage>.th.md`.

**Usage:** These are optional recording templates, **not** a requirement to maintain new duplicate Markdown files or proof that a Human Gate was approved. Keep actual project and company records in authorized systems; this public knowledge repository must stay sanitized.
