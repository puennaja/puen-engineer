## Candidate Principles (ยังไม่ Approved)

### EF-G13 — ให้เอกสารมีเจ้าของและปรับได้พร้อมระบบ

- **ชื่ออังกฤษ:** Make Documentation Owned and Changeable
- **ต้นฉบับที่เกี่ยวข้อง:** Documentation Is Like Code; Google Wiki; Documentation Reviews
- **Layer A — ความหมาย / เมื่อไรควรใช้:** เหมาะกับเอกสารระยะยาว Reference ใกล้โค้ดและบันทึกการตัดสินใจ
- **Layer B — Trade-offs / ข้อควรระวัง:** งานจิ๋วอาจไม่คุ้มภาระ และเอกสารบน Git ก็ยังเก่าได้
- **Layer C — หลักฐานและสถานะ:** อ้างอิงเฉพาะหัวข้อข้างต้นจากบทเต็ม แต่ยังไม่ได้ตรวจหลักฐานอิสระหรือลองใช้จริง; Confidence: สูงสำหรับการระบุแนวคิดในบท ต่ำ/ยังไม่ประเมินสำหรับการยกเป็นกฎสากล; ทบทวนเมื่อมีหลักฐานใหม่หรือ Pilot ไม่สนับสนุน
- **Status:** Candidate

### EF-G14 — เขียนให้ผู้อ่านหลักและเป้าหมายหลัก

- **ชื่ออังกฤษ:** Write for One Primary Reader and Purpose
- **ต้นฉบับที่เกี่ยวข้อง:** Know Your Audience; Documentation Types; Documentation Philosophy
- **Layer A — ความหมาย / เมื่อไรควรใช้:** เลือกรูปแบบเอกสารจากผู้ใช้งานและเป้าหมาย
- **Layer B — Trade-offs / ข้อควรระวัง:** แยกมากไปเพิ่มต้นทุนการค้นหาและดูแล
- **Layer C — หลักฐานและสถานะ:** อ้างอิงเฉพาะหัวข้อข้างต้นจากบทเต็ม แต่ยังไม่ได้ตรวจหลักฐานอิสระหรือลองใช้จริง; Confidence: สูงสำหรับการระบุแนวคิดในบท ต่ำ/ยังไม่ประเมินสำหรับการยกเป็นกฎสากล; ทบทวนเมื่อมีหลักฐานใหม่หรือ Pilot ไม่สนับสนุน
- **Status:** Candidate

### EF-G15 — ยกเลิกเอกสารเก่าหรือที่ซ้ำอย่างชัดเจน

- **ชื่ออังกฤษ:** Deprecate Stale or Competing Sources
- **ต้นฉบับที่เกี่ยวข้อง:** Documentation Is Like Code; Deprecating Documents
- **Layer A — ความหมาย / เมื่อไรควรใช้:** กำหนดแหล่งหลักและชี้เอกสารเก่าไปที่ฉบับใหม่
- **Layer B — Trade-offs / ข้อควรระวัง:** ลบประวัติทิ้งอาจทำให้ตรวจเหตุผลย้อนหลังยาก
- **Layer C — หลักฐานและสถานะ:** อ้างอิงเฉพาะหัวข้อข้างต้นจากบทเต็ม แต่ยังไม่ได้ตรวจหลักฐานอิสระหรือลองใช้จริง; Confidence: สูงสำหรับการระบุแนวคิดในบท ต่ำ/ยังไม่ประเมินสำหรับการยกเป็นกฎสากล; ทบทวนเมื่อมีหลักฐานใหม่หรือ Pilot ไม่สนับสนุน
- **Status:** Candidate
